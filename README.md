# MPS Payments for Odoo

The Odoo module `payment_mps`: MPS as a payment provider in Odoo 20, on the MPS-hosted checkout.

Install it by copying `payment_mps/` into your Odoo addons path, then Apps › Update Apps List and install
"Payment Provider: MPS". Its page on the Odoo Apps Store describes the setup.
